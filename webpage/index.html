Welcome to DoriteLover's guide on how to make and manage your own Minecraft server!

So you want to make your own Minecraft server? Hell yeah! you're totally in the right place for this.

READ BEFORE PROCEEDING

Note: This guide is oriented towards Minecraft: Java Edition

1: Preparation

1.1 Requirements

Make sure you have these things ready and working:

Required, Forced

  • A device that is good enough to host and run Minecraft
  • A stable internet connection (At least 50mbps of upload speed is recommended if you are doing this to play with your friends)
  • Storage device (e.g., hard drive or SSD) with sufficient space for the server files and world data (More than 30GB is recommended)
  • USB Flash Drive at least 16GB for host setup installation media

2: Installation

2.1 Installing Debian

Debian is VERY recommended for hosting something like this as it's super stable and have support for old devices too. You might not be familiar with the operating system but this guide can help you get through it!

1) Download debian 13.6.0 or later: https://cdimage.debian.org/debian-cd/13.6.0-live/amd64/iso-hybrid/

When you get to this page, click here to download my recommended ISO file.

2) Create a bootable USB drive

For Windows

First step, plug in your USB flash drive and download Rufus. Click on the first option and it should download the right version for your system that you are gonna use it to flash your USB flash drive with the Debian ISO.

Second. Open Rufus that you recently downloaded, set the options to whatever that matches your server system or the host that you're gonna use to host a minecraft server on.

Third. Click start and wait until the flashing finish, all the data on the USB will be lost so make sure you also back them up!

For MacOS/Linux

Option 1: BalenaEtcher (Easy)

Firstest First. Grab BalenaEtcher from their website: https://etcher.balena.io/

Note for Arch Linux and Arch Linux based Distrobutions: If you've downloaded BalenaEtcher in an AppImage format, don't forget to give permission for yourself to open the AppImage.

Second, plug your USB flash drive into your device.

Third, Put the Debian ISO into BalenaEtcher and press Flash then wait.
